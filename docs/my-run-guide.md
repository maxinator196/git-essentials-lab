# Library Demo Run Guide

## Prerequisites

- Git 2.23 or newer
- JDK 17 or newer (both `java` and `javac` must be available on PATH)
- Python 3.9 or newer

## Running the Demo

To run the library demo, execute the following command from the root of the repository:

```text
python3 run.py demo
```

## What the Demo Does

The demo demonstrates the core library system functionality without any external dependencies:
1. Initializes the library catalog with sample books.
2. Registers library members (students and faculty).
3. Demonstrates book borrowing according to policy limits.
4. Generates loan receipts.
5. Demonstrates returning books and calculating overdue fees.
6. Performs catalog search by title.
